# Imagenes institucionales

Guarda aqui los recursos fijos del colegio, por ejemplo:

- `colplinista.png`
- `escudo-colegio.png`
- `firma-rectoria.png`

En Angular se usan desde la raiz publica:

```html
<img src="/images/institucion/colplinista.png" alt="Logo institucional">
```

Si vas a reemplazar el logo, conserva el mismo nombre `colplinista.png` o actualiza la ruta en el componente que lo use.
